# 🛸 하코 NFZ 조회 — 안드로이드 앱

취미로 드론을 날리는 분들을 위한 비행구역 확인 앱입니다.
지금 있는 곳이나 지도에서 누른 곳이 비행금지구역·비행제한구역·관제권인지, 날씨와 야간 여부까지 합쳐서 알려줍니다.

## 📥 내려받기
**👉 [최신 버전 APK 내려받기](https://github.com/moto2345/nfz-android/releases/latest/download/hako-nfz.apk)**

## 설치 방법
1. 위 링크를 휴대폰에서 눌러 `hako-nfz.apk`를 내려받습니다.
2. 내려받은 파일을 누릅니다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켭니다.
4. **설치**를 누릅니다. "Play 프로텍트" 경고가 나오면 **무시하고 설치**를 누르세요. (Play 스토어를 거치지 않은 앱이라 나오는 안내입니다)
5. 처음 실행하고 내 위치 버튼을 누를 때 **위치 권한을 허용**해 주세요.

## 알아두세요
- 앱 내용은 인터넷으로 항상 최신 버전을 불러옵니다. 인터넷 연결이 필요합니다.
- 비행 기록과 저장한 장소는 휴대폰에만 저장됩니다. [기록] 탭 → 백업·내보내기에서 백업하면 휴대폰의 **다운로드** 폴더에 저장됩니다.
- 새 버전이 나오면 같은 링크에서 내려받아 설치하면 기록은 그대로 두고 업데이트됩니다.

> ⚠️ 참고용입니다. 실제 비행 전에는 [드론 원스톱 민원서비스](https://drone.onestop.go.kr)에서 확인하고 필요한 비행승인·촬영허가를 받으세요.
